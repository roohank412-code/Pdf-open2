# Exam Result 2026 — Secure Result Viewer

A production-ready, fully responsive static exam result verification portal designed for GitHub Pages. Features a clean modern UI, customized HTML5 canvas CAPTCHA generation with noise and strike lines, and seamless PDF result rendering.

## 📁 Folder Structure

```text
ExamResultPortal/
│
├── index.html         # Main HTML layout and markup
├── style.css          # Responsive mobile-first stylesheet
├── script.js          # Core form submission and UI state handler
├── captcha.js         # Canvas-based 6-character CAPTCHA generator
├── result.pdf         # The exam result PDF document to be displayed
├── README.md          # Documentation
└── assets/
      ├── logo.png     # Logo image asset
      └── spinner.gif  # Spinner image asset
